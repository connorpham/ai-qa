# Lessons — in transit, not in residence

## How to use this file

Pipelines read **this section and the index only**, then open just the entries
whose tags match the work in hand. Nobody reads the whole file, so nobody should
write as though they will.

**A lesson's destiny is to leave.** Every entry here is waiting to graduate:

| If the lesson is… | It graduates into… |
|---|---|
| machine-checkable | a gate script — with a mutation proving it can go red |
| unconditional, every time | the workflow's own text |
| a recurring environment quirk | `known-issues.md`, with a KI id |

After it graduates, **delete it from here**. A lesson that stays forever was
never a lesson; it was a note.

**If a rule keeps being violated, it is not a lesson — it is a missing gate.**
Willpower on a deadline is not a control.

Cleanup thresholds: more than 25 rows in the index, or more than 250 lines in
the file, and a consolidation pass becomes due work.
