# Known issues — the KI registry

Every new finding gets checked against this list **before** it is called a bug.
Re-reporting a known issue dilutes signal and costs the team more than the
report is worth.

What belongs here: environment quirks, recurring tool failures, accepted
deviations, and defects that have been triaged and consciously deferred. Each
one gets a stable id so reports can cite it instead of re-describing it.

What does not belong here: a defect nobody has decided about yet. That is an
open bug, not a known issue, and parking it here is how it gets forgotten.
